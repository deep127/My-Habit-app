# Little Habits v2

Mobile-first habit tracker built as a static PWA.

Features:
- Separate Home / Progress / Charts / Calendar / Quotes / More screens
- Habit streaks and points
- Interactive garden and shop
- Calendar notes saved per date
- Backup / restore JSON
- Browser notification permission
- LocalStorage persistence
- PWA manifest + service worker

Deploy the three files at the repository root on Vercel.
